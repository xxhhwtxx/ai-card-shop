🚀 初次配置向导

需要配置一次 GitHub Gist 作为数据源，之后就永久使用，无需服务器。

1创建 GitHub Gist

点击下方链接，登录 GitHub 后创建一个新的 Gist：

🔗 gist.github.com/new
2填写 Gist 内容

文件名填 data.json，内容粘贴如下（选择 Public）：

{ "products": [], "settings": { "email": "", "siteName": "AI 卡密站", "siteDesc": "精选主流 AI 工具卡密，安全稳定，即买即用。", "qrImage": "", "contactExtra": "" } }
3获取并填入 Raw URL

创建后点 Gist 页面右上角 Raw 按钮，复制地址栏链接（以 https://gist.githubusercontent.com/ 开头）：

4填入 GitHub Token（用于写入数据）

前往 GitHub Token 生成页，勾选 gist 权限，生成后粘贴到下方：

⚠️ Token 只保存在你自己的浏览器 localStorage 中，不会上传到任何地方

请填写完整的 Gist Raw URL 和 GitHub Token
